-------------------------------------------
Branch tip ee69ab21d accumulated stable+clones in ONE slice named `out` and
returned it; the Ingress block (worktree_clone.go, "Route clones (plan §4.2
step 4)") read/wrote `out` and called cloneIngresses(out, ...) /
clonedServiceNames(out, ...).

The merge commit 2dd4ff533 refactored WorktreeClones to return ONLY clones
(accumulator renamed `clones`; stampWorktreeClones now wraps it and re-adds
stable entities; sibling-DNS rewrite switched to a fresh `stamped` slice) —
but pasted the branch's Ingress block in VERBATIM, still referencing `out`:

    // worktree_clone.go:257-260 (as merged)

        clonedServiceNames(out, suffix, worktree))...)

`out` no longer exists in scope -> package does not compile. Pre-merge master
(bc49b598e / 2dd4ff533^1) has no Ingress block and no `out` in WorktreeClones;
the regression is introduced by this merge. Classification: INTEGRATION BUG
(botched merge resolution). The branch-only run (ee69ab21d + 7138e8d32) was
valid because that tree compiled; the merged tree does not.

build the fully stamped set BEFORE the Ingress block and append the ingress
